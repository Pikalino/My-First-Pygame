# Pygame Asteroids

A simple Asteroids-style game built with Python and Pygame.

This project was created while following the Boot.dev Pygame course.  
The goal was to practice Python fundamentals, object-oriented programming, game loops, collision detection, and basic project structure.

## Features

- Player movement and rotation
- Shooting projectiles
- Asteroid spawning and splitting
- Collision detection
- Score/game state logic
- Modular Python files

## Tech Stack

- Python
- Pygame
- uv

## What I Learned

- Game loop structure
- Object-oriented programming in Python
- Handling keyboard input
- Collision detection
- Splitting logic for game objects
- Organizing a small Python project
